# Network Diagnostic Monitor

Windows network diagnostics, a local read-only network-status dashboard, and a prepared Asuswrt-Merlin port boundary.

The current candidate is V2.12-RC3.1.1. Its source import and GitHub workflow setup are being prepared on [rc3.1.1-import](https://github.com/Helminiak/NETWORK-DIAGNOSTIC-MONITOR/tree/rc3.1.1-import) for review through a pull request.

The first main-branch commit initializes the repository; it is not a runnable or production-approved release. Use the candidate branch while the import pull request is open.
